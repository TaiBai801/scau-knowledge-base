## 四项前端布局问题修复

### 问题1：Menu按钮消失
- 原因：`.VPNavBarHamburger { display: none !important }` 只在768-959px范围内隐藏了汉堡菜单，但<768px时VitePress默认就应该显示菜单
- 修复：新增 `@media (max-width: 767px) { .VPNavBarHamburger { display: flex !important } }` 确保移动端菜单始终可见；新增 `@media (min-width: 960px) { .VPNavBarHamburger { display: none !important } }` 明确桌面端隐藏

### 问题2：大屏侧边栏诡异
- 原因：`.VPContent { padding-left: 220px }` 在768-959px被强加，但首页是 `layout: home` 没有侧边栏却被误加了左偏移
- 修复：改用 `.VPContent:not(.is-home) { padding-left: 220px }` 跳过首页；侧边栏≥960px宽度从220px增至240px
- 关键发现：VitePress 首页的 VPContent 元素会自动加上 `.is-home` 类（在 VPContent.vue 中定义）

### 问题3：首页比例超级异常
- 原因：之前用 `.Layout.home` 选择器，但 VitePress 的 Layout div 并不加 `.home` 类！所有首页样式规则实际上从未生效
- 修复：全面改用 `.VPContent.is-home` 选择器（这才是 VitePress 真正的首页标识）
  - 首页 padding-left: 0（不受侧边栏影响）
  - 首页 VPDoc 不用侧边栏 padding
  - Hero 容器 max-width: 960px，Features 容器 max-width: 1100px
  - 超宽屏约束排除了首页（`:not(.is-home)`）

### 问题4：本页目录盖住快捷导航
- 原因：VitePress 右侧 TOC（outline）的 z-index 较高，定位为 sticky/absolute，会覆盖底部 CustomFooter
- 修复：
  - `.VPDocAside` + `.VPDocAsideOutline` z-index 降为1，position: relative
  - `.custom-footer` z-index 提升到10
  - `.VPDoc.has-aside` padding-bottom: 4rem，增加底部空间防重叠

### 构建结果
- vitepress build → 3.75s ✓

## Hero 标题顶部被裁切修复

### 问题
- 首页 Hero 标题「机电学院知识库」顶部被截掉，只能看到字体下半部分
- 根因：VitePress 默认给 `.VPHero .name` 内部套了 `<span class="clip">`，使用 `background-clip: text` + 渐变背景实现渐变色文字效果。当外层 `.name` 被覆盖为纯色后，内层 `.clip` span 仍保留 `background-clip: text`，导致文字渲染异常，顶部被裁切

### 修复
- 新增 `.VPHero .name .clip` 和 `.VPHero .name span` 规则：
  - `-webkit-text-fill-color: var(--brand)` — 强制纯色
  - `background: none` — 清除渐变背景
  - `background-clip: unset` — 移除裁切效果

### 附带优化
- 同时将 `VPContent { padding-top: 0 }` 恢复为 `padding-top: var(--vp-nav-height)`，防止内容被fixed导航栏遮挡
- 首页 VPHero padding 从 `4rem 0 3rem` 调为 `2rem 0 3rem`（nav-height 已撑开顶部空间）
- VPHero 加 `overflow: visible` 防院徽 scale(1.05) 被裁

### 构建结果
- vitepress build → 3.79s ✓
