## ⚠️ push 失败真因：schannel 证书吊销检查（重要，以后先查这个）
- 症状：`CONNECT tunnel failed 502` + `schannel: server closed abruptly`，
  `curl https://github.com` = 000，连试 14 次 5 分半全是 000，看着像被墙
- 但 `api.github.com`=200、`codeload.github.com`=301 都正常 → 排除代理整体失效
- `curl -sS` 才暴露真实错误：`schannel: CRYPT_E_NO_REVOCATION_CHECK (0x80092012)`
  —— Windows schannel 连不上证书吊销列表服务器，就中断整个 TLS 握手
- **解法**：`git -c http.schannelCheckRevoke=false -c http.proxy=<P> push origin main`
  加上后 github.com 立刻 200，push 一次成功
- 结论：以后 push 报 502 / server closed abruptly，**先怀疑吊销检查，不要先怀疑代理节点**
