## ⚠️ 经验教训：VitePress 自定义样式三原则

### 1. Vue Scoped 样式会吞掉你的 CSS
- VitePress 导航栏组件都是 `<style scoped>`，选择器变成 `.class[data-v-xxx]`（特异性 0,2,0）
- **裸写类名 `.VPNavBarMenuLink` 必被覆盖**，必须用父选择器 `.VPNavBar .VPNavBarMenuLink` 提特异性
- 所有覆盖属性加 `!important`，不要省

### 2. VitePress 宽屏（≥960px）会重构导航栏
- `.title` 变成 `position: absolute` 覆盖侧边栏上方
- `.content-body` 独立获得背景色 `var(--vp-nav-bg-color)`
- `.VPNavBar` 自身背景变 `transparent`
- **现象**：导航栏在宽屏时"分裂"成左右两个独立色块
- **解法**：`@media (min-width: 960px)` 强制子区域透明
