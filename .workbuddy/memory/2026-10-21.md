## 踩坑记录
验证脚本用 `/tmp/xxx` 存文件会踩 Windows 路径分歧：MSYS 工具（curl/grep）写 `/tmp`
落到 MSYS 目录，而 Windows 程序（node/python）把 `/tmp` 解析成 `D:\tmp`。
**结论：跨 curl + node/python 的临时文件一律放项目内相对路径**（如 `.workbuddy/xxx`）。

## ⚠️ 编辑 CSS 块的血泪教训（两次构建失败同因）
改 `<style>` 里某个选择器块时，如果 old_string 以**属性行结尾（不含结尾的 `}`）**，
替换后原来的 `margin-bottom: 16px;\n}` 等剩余属性会变成**孤立属性 + 多余 `}`**，
postcss 报 "Unexpected }"。**规则：替换 CSS 块必须把结尾 `}` 纳入 old_string**。
同理 FocusPage 一次编辑把两行语句并成一行（同行 ASI 不生效）导致 babel 报错。
提交前务必跑一次 CSS 大括号平衡检查（{ 数 == } 数）。
