## ⚠️ 踩坑：git push 报 proxy 502 的解决办法（重要，可复用）
- 现象：git push 一直报 CONNECT tunnel failed, response 502 / schannel: server closed abruptly，但 curl 走同一代理访问 github.com 正常（CONNECT 200）
- 原因：git 没正确读 env 的 http_proxy/https_proxy
- 解法：显式用 -c 传代理
  git -c http.proxy=http://127.0.0.1:53278 -c https.proxy=http://127.0.0.1:53278 push origin main
  （代理地址从 env https_proxy 拿，端口每次可能变，先 env|grep -i proxy 看）
