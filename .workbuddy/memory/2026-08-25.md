### 技术要点（坑）
- EdgeOne 云函数目录是 `node-functions/`（不是 functions/），导出 `onRequestPost({request})`
- putBucketCors 需 Content-MD5 头；COS 签名 header 值要 URL 编码（quote safe='-_.~'），多 header 用 & 连接
- COS 预签名 URL 手算签名：HMAC-SHA1(SecretKey, KeyTime) → sha1(FormatString)
- 上传 key 用「课程码+时间戳+随机串+ext」纯 ASCII，避开中文签名/编码坑
