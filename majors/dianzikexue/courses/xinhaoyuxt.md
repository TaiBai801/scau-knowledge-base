## ① 课程介绍

| 项目 | 内容 |
|------|------|
| **课程名称** | 信号与系统 |
| **课程编号** | B2040028 |
| **学时** | 64 学时（理论 56 + 实验 8） |
| **学分** | 4 |
| **开设学期** | 大二上学期 |
| **先修课程** | 高等数学 A、电路原理、复变函数与积分变换 |
| **使用教材** | 《信号与系统》（第三版），郑君里，高等教育出版社 |
| **授课教师** | XXX 老师 |
| **课程简介** | 信号与系统是电子信息类专业的核心基础课，系统讲授信号分析、系统响应的时域和频域分析方法。涵盖连续时间系统的卷积运算、傅里叶变换、拉普拉斯变换，以及离散时间系统的 z 变换等核心内容。考研必考科目。 |
